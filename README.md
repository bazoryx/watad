# وتد — Watad

تطبيق المحافظة على الصلاة: ستريك المسجد وستريك المحافظة، وتقويم ملوّن، وأعذار وحماية للستريك. هذه هي النسخة التجريبية الأولى، وكل البيانات محفوظة على الجهاز بدون حسابات.

## التشغيل

تحتاج Flutter 3.27 أو أحدث.

```bash
cd watad
# ينشئ مجلدات iOS وAndroid فقط، ولا يغيّر ملفات lib ولا test
flutter create . --platforms=ios,android --org com.yourdomain
flutter pub get
flutter test        # 20 اختبارًا: منطق الستريك والبيانات والشاشات
flutter run
```

غيّر `com.yourdomain` إلى دومينك (مثلًا `app.watad`)، لأنه يصير معرّف التطبيق في المتجرين ولا يتغيّر بعد النشر.

اسم التطبيق تحت الأيقونة:
- Android: في `android/app/src/main/AndroidManifest.xml` غيّر `android:label` إلى `وتد`.
- iOS: في `ios/Runner/Info.plist` أضف `CFBundleDisplayName` بقيمة `وتد`.

## ما في هذه النسخة

| الجزء | الملف |
|---|---|
| قواعد الستريك (المسجد، المحافظة، القضاء، الأعذار، التجميد، السكور) | `lib/core/streak_engine.dart` |
| مواقيت الصلاة على الجهاز بطريقة كل دولة (مكتبة adhan) | `lib/core/prayer_times.dart` |
| الحفظ المحلي | `lib/data/repository.dart` |
| الحالة العامة | `lib/state/app_state.dart` |
| الألوان والخطوط من التصميم | `lib/theme/app_theme.dart` |
| النصوص بالعربي والإنجليزي | `lib/l10n/strings.dart` |
| الشاشات: الرئيسية، التسجيل، التقويم، الإعدادات | `lib/ui/` |

### الأجهزة القابلة للطي

التخطيط يتبدّل حسب عرض النافذة، لا حسب اسم الجهاز (الحد 600 نقطة):
- الجوال والشاشة الخارجية لآيفون Duo وGalaxy Z Fold8 (حوالي 466 نقطة): عمود واحد وشريط سفلي.
- الشاشة الداخلية (حوالي 890 نقطة): شريط جانبي وعمودان، والفراغ بين العمودين يقع على خط الطي.

للتجربة: محاكي Android بجهاز "7.6 Fold-in with outer display"، ومحاكي iPhone Duo في Xcode (البناء بـ iOS 27.1 SDK أو أحدث حتى يملأ التطبيق الشاشة).

### قواعد الستريك كما هي مبرمجة

- **المسجد:** +1 لكل صلاة في المسجد. البيت أو القضاء أو الفوات يصفّره.
- **المحافظة:** +1 لكل صلاة في وقتها (مسجد أو بيت) أو قضاء قبل دخول التالية. القضاء المتأخر أو الفوات يصفّره.
- **صلوات اليوم غير المسجلة** لا تكسر شيئًا حتى منتصف الليل، وبعدها تُحسب فائتة.
- **التجميد:** تجميدان في الشهر يحميان الستريك تلقائيًا إذا نُسي التسجيل، ولا يُصرف التجميد إذا لم يكن هناك ستريك.
- **العذر:** الصلوات غير المسجلة أثناء العذر لا تُحسب، والصلاة في البيت أثناء العذر لا تصفّر ستريك المسجد. الصلاة المسجلة «لم أصلّها» تصفّر الاثنين.
- **أفضل رقم** يُحفظ لكل ستريك.

الستريك يُعاد حسابه من أول يوم في كل مرة، فتعديل أي تسجيل قديم يعطي الأرقام الصحيحة دائمًا.

## الخطوة القادمة

1. التنبيهات وصوت الأذان والإقامة (flutter_local_notifications).
2. تحديد الموقع بالـ GPS، وتنبيه أقرب مسجد.
3. الحسابات والمجموعات ولوحة المدير (Firebase أو Supabase).
4. القرآن والورد اليومي، والسنن، والإنجازات.
